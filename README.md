# SP Git Flow Lab

Учебный проект к лабораторной работе №5 «Многоветочная модель технологического
процесса на основе Git» (дисциплина «Современные платформы программирования»).

Проект — маленький консольный калькулятор на JavaScript без внешних зависимостей.

## Запуск

```bash
node src/index.js
```

## Ветки

| Ветка | Назначение |
|---|---|
| `main` | стабильные релизы, изменения только через `release/*` и `hotfix/*` |
| `develop` | интеграция готовых фич, база для `release/*` |
| `feature/multiply` | новая функциональность — умножение |
| `feature/history` | новая функциональность — история операций |
| `release/1.0.0` | подготовка релиза 1.0.0 |
| `hotfix/1.0.1` | срочное исправление деления на ноль |

## Модель ветвления

Используется Git Flow (Vincent Driessen):
<https://nvie.com/posts/a-successful-git-branching-model/>
